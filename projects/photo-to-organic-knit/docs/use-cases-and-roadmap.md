# 使用场景、扩展方向与实际价值

## 什么时候适合用

判断标准不是“是否喜欢毛线”，而是内容是否需要在保留辨识度的同时获得亲和、手作、收藏或编辑气质。

研究展厅已经将这一判断落到四组实演：家庭成长册选择针织来放大亲密感；旅行纪念选择木刻来保证缩略图识别；社区公益选择彩色玻璃把多人行动组织为共同体符号；独立面包店选择剪纸来建立编辑层级和可排版留白。

四组实演还继续进入了代码原生的成品布局：ImageGen 只提供无字艺术底图，标题、日期、坐标、指标、品牌占位与免责声明全部由 HTML/CSS 确定性排版。这种拆分比要求图像模型一次性生成完整海报更接近真实生产，也更容易审核、修改、本地化和建立品牌规范。

### 1. 品牌与活动主视觉

- 输入：产品、门店、创始人、地标或活动照片；
- 输出：留白充足的 KV、封面、邀请函和社媒头图；
- 价值：比通用风格滤镜更容易形成一个可讲述的视觉概念；
- 注意：Logo、价格和长文案应在设计软件中后期叠加。

### 2. 旅行、城市与自然纪念海报

- 输入：山川、铁路、街道、建筑、露营或旅行人物；
- 输出：纪念海报、明信片、路线封面和收藏卡；
- 价值：路径、桥、山口、河流很适合转化为毛线动线和负形符号。

### 3. 儿童与家庭内容

- 输入：家庭照片、宠物、成长瞬间；
- 输出：绘本扉页、成长卡、纪念册封面；
- 价值：纤维材料天然传递柔软和亲近感；
- 注意：涉及儿童与家庭照片时要限制上传、存储和公开范围。

### 4. 节日、公益和社区传播

- 输入：社区活动、志愿者、节庆场景；
- 输出：温暖的主题卡片和活动海报；
- 价值：手工感能弱化机构式宣传的距离感，同时保留事件锚点。

### 5. 编辑出版与内容栏目

- 输入：报道摄影或文章核心图片；
- 输出：杂志封面、播客封面、专题首图；
- 价值：大面积留白和紧凑徽章式主体适合编辑排版。

### 6. 产品概念与包装提案

- 输入：食品、家居、户外和文创产品；
- 输出：包装插画方向、季节限定视觉、礼盒概念；
- 价值：能快速测试“手作、自然、柔软、可收藏”的品牌方向；
- 注意：生成图只能作为概念资产，印刷前需人工重绘、分色和版权复核。

## 不适合直接使用的场景

- 需要逐像素还原人物身份的证件、新闻事实或医学图像；
- 需要准确文字、价格、参数和法律条款的最终广告稿；
- 需要真正可编织针法、工业打版或生产 CAD 的制造任务；
- 需要大批量完全一致角色和构图、但没有后处理流水线的内容；
- 对模型上传隐私照片有合规限制的组织环境。

## 从 Skill 到可用产品的扩展路线

> 当前进度：统一 Essence Schema、六种 Effect Profile、四种 Scenario Profile、四种 Delivery Profile、自动路由和 Prompt 编译器已经在 `extension/photo-to-conceptual-art` 中实现。下面阶段 A 的核心骨架已落地，后续重点转向图像检查、真实批量基准与设计工具连接。

### 阶段 A：把一次生成变成可复现案例

1. 保存输入、最终 Prompt、输出和失败版本；
2. 固定模型版本、时间、画幅和生成次数；
3. 用结构化表单记录 retain / transform / discard；
4. 将文字从图片生成中拆出，允许后期排版；
5. 建立人物、动物、建筑、自然和产品的最小测试集。

实际收益：团队不再靠聊天记录寻找“那次效果不错的提示词”。

### 阶段 B：增加自动检查与人审门禁

可增加：

- 输入与输出方向一致检查；
- OCR 标题拼写检查；
- 主体/颜色锚点相似度；
- 留白占比和主体包围盒测量；
- 参考图特有对象泄漏检测；
- 一次只修复一个失败项的迭代记录；
- 生成成本、时延和重试次数统计。

实际收益：降低人工巡检量，知道失败发生在哪一层。

### 阶段 C：形成场景预设和批量生产系统

将当前单一风格拆成可组合参数：

- 内容预设：人物、宠物、城市、自然、产品；
- 构图预设：徽章、封面、横幅、方形卡片；
- 概念装置：负形、路径、织物岛、尺度对比、分层拼贴；
- 材质预设：粗针织、钩针、毛毡、马海毛、刺绣；
- 交付预设：无字底图、短题字海报、透明主体、印刷安全区。

实际收益：同一品牌可以在不同内容上保持一致，而不是每次重新发明 Prompt。

### 阶段 D：连接真实设计与制造流程

- 输出分层素材或可编辑遮罩，交给 Figma/Photoshop；
- 对接 DAM，记录来源、授权、生成模型和版本；
- 建立品牌色、禁用对象和审稿角色；
- 对需要实物落地的图案，增加人工矢量化、针法映射和打样；
- 对商品化结果增加版权、肖像权和商标审核。

实际收益：从“漂亮样图”升级为可以进入组织流程的受控资产。

## 最值得研究的五个方向

### 1. 语义保真与创造性变化的平衡

需要同时测量“还能认出来吗”和“是否真的重新设计”。两者往往相互拉扯，适合用双指标和人工盲评研究。

### 2. Prompt 消融实验

分别去掉三分法、视觉隐喻、三项结构变化、风格参考、负向约束和质检循环，比较哪一项贡献最大。

### 3. 参考图泄漏与风格边界

测试参考图中的火车、桥梁和题字是否在无关输入中出现，并比较单图、多图与纯文本风格描述。

### 4. 自动构图评价

使用显著性、检测框、OCR 和图像嵌入建立可解释评分，但保留设计师最终裁决，避免把“审美”压缩成单一分数。

### 5. 跨模型和版本稳定性

在固定输入与 Prompt 下记录不同模型、版本、质量档和多轮编辑的成功率、成本与漂移。

## 实际价值分层

| 层级 | 直接价值 | 成熟所需条件 |
| --- | --- | --- |
| 个人创作 | 快速获得有概念的旅行、家庭和内容封面 | 一张合法输入图和人工挑选 |
| 设计团队 | 统一 briefs、减少重复沟通、快速探索主视觉 | Prompt 归档、无字输出、设计师后处理 |
| 品牌组织 | 建立可复用的柔性手作视觉资产线 | 品牌预设、版本控制、审批与 DAM |
| 平台产品 | 提供照片到海报的垂直生成体验 | 表单化输入、质量评分、成本与安全控制 |
| 学术研究 | 研究隐性设计知识如何被 Agent 执行 | 数据集、消融、盲评、统计和可复现记录 |

## 优先级建议

如果继续推进，优先做三件事：

1. **先做无字底图模式和后期排版模板**，解决商业使用中最常见的文字可靠性问题；
2. **再做 20–50 张跨题材基准与消融**，判断规则是否真的稳定有效；
3. **最后做预设化产品界面和批量能力**，避免在质量尚未可测时过早包装。
