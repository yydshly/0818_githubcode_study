# 能力、原理、意义与边界

## 一句话判断

Photo to Organic Knit 是一套把“照片毛线化”升级为“概念驱动视觉重构”的 Codex Skill。它不生产像素，也不训练模型；它负责让 Agent 在调用 ImageGen 前做出更像设计师的选择，并在调用后按统一标准检查结果。

## 上游实现清单

固定版本：`b84efe522e758649e46fe59f34d700eb60bedc12`。

| 文件 | 作用 | 不负责什么 |
| --- | --- | --- |
| `photo-to-organic-knit/SKILL.md` | 触发描述、12 步工作流、不可破坏的设计约束、提示构造 | 不含图像算法和 API 实现 |
| `references/style-spec.md` | 材料、构图、负形、织物岛、标题和避免项 | 不提供可执行渲染器 |
| `assets/style-reference.png` | 提供触感和成品质量参照 | 不是要复制的主体模板 |
| `agents/openai.yaml` | 展示名称与默认调用提示 | 不声明模型版本或依赖 |
| `assets/*-before-after.png` | 展示上游作者的火车与森林案例 | 不是批量基准数据集 |

## 它怎样工作

### 1. 读图与取舍

Agent 先识别画幅、主体、轮廓、动作、情绪和 2–5 个不可缺少的视觉锚点。随后把元素分成三组：

- `retain`：失去后就无法认出原图的主体或关系；
- `transform`：有叙事价值，但应该变成符号、织物块、毛线路径或负形；
- `discard`：会把结果拖回写实照片的连续背景和次要细节。

这一层解决的是“生成模型应该关注什么”，而不是“每个像素如何计算”。

### 2. 建立单一概念

Skill 要求先写一句艺术指导，例如把峡谷和举起的双手变成一扇门。它还要求只选一个主要设计装置，最多增加两个辅助装置，避免把所有技巧堆进同一张图。

可选装置包括负形符号、不对称纪念碑、织物岛、路径或丝带、尺度对比和分层拼贴。这里的意义是把审美偏好变成有限的决策空间。

### 3. 结构重构

输出必须至少改变原图的三项结构：层级、尺度、间距、轮廓、视点、连续性、分层、负形或视觉路径。主体约占画布宽度 55–60%、高度 50–55%，四周保留暖象牙色空间。

这些数字是生成约束，不是像素级保证。它们能影响模型，但没有程序测量和强制纠偏。

### 4. 多图条件生成

调用 ImageGen 时：

- 原照片提供主体身份和关系；
- `style-reference.png` 只提供针织、钩针、圈圈纱、毛毡和纤维的质量参照；
- 文本提示规定保留、转化、舍弃、构图、材料、题字和避免项。

上游反复强调禁止复制参考图的火车、桥梁、山丘、色板或题字。这是在多参考输入中主动分离“内容角色”和“风格角色”。

### 5. 视觉质检与迭代

结果需要检查方向、主体识别、概念转化、层级、留白、材料真实性、边缘有机性和文字准确度。失败时一次只修一个问题。这是一条人工可理解的迭代策略，但上游没有自动评分器。

## 本研究的独立实演

### 输入

一张原创生成的横版旅行照片：黄色外套的单人划红色独木舟，河道以 S 形穿过芦苇并通向雾中山脉。

### 设计决策

| 类型 | 本次选择 |
| --- | --- |
| Retain | 红舟、黄色外套、S 形旅程、山脉轮廓、少量芦苇 |
| Transform | 河流变成编织毛线路径；山变成不对称织物岛；雾变成马海毛纤维 |
| Discard | 写实天空、水面反射、连续植被、摄影景深和背景杂讯 |
| Concept | 河流是一根线，把小小旅行者带过山间之门 |
| Title | `Follow the Current` |

### 可观察结果

- 横版方向得到保持；
- 红舟、黄衣和山谷关系仍可识别；
- 河流由真实水体变成画面的主导编织路径；
- 写实背景被拆为留有缝隙的材料岛；
- 标题正确显示为三个单词；
- 没有复制参考图中的火车和桥梁。

这组案例说明 Skill 能推动真正的构图再解释，而不只是表面纹理迁移。但一次成功案例不能代表统计稳定性。

## 同一意境的多效果扩展

本研究进一步固定同一源图、辨识锚点和“一根路径带着小小旅行者穿过山间之门”的隐喻，只替换材料合同，生成针织、分层剪纸、陶瓷浮雕、彩色玻璃、木刻版画和微缩场景六种结果。

实验说明，Skill 可以把“语义提取”和“效果表现”解耦：共享层负责主体、关系、情绪与隐喻；效果层分别规定材料、空间机制、手工缺陷、避免项和后期用途。它并不完全控制像素，但能显著控制模型解释这份意境的方向。

六种材料产生了不同的实际表达：针织更亲和，剪纸更适合编辑留白，陶瓷更像收藏物，玻璃更具象征性，木刻更适合高对比出版，微缩场景则最适合继续发展为空间或动画叙事。

## 已实现的目标驱动扩展

研究层已新增 `extension/photo-to-conceptual-art`，不修改上游 Skill。它使用统一 Essence JSON 保存锚点、关系、情绪、路径和隐喻，再把场景、效果与交付规格作为 14 个独立 Profile 组合。标准库 Prompt 编译器支持自动效果路由和显式覆盖，并对缺字段、未知效果和场景不允许的交付组合明确失败。

当前自动路由为：家庭纪念→有机针织→书籍封面；旅行内容→木刻→旅行日志；公益报告→彩色玻璃→A4 报告；季节活动→分层剪纸→4:5 海报。编译输出同时包含路由原因、ImageGen Prompt、输出变体和目标质量门禁。

一次未见海岸骑行照片的前向测试进一步比较了自动木刻与人工剪纸覆盖。两者首轮都保留了人、车、灯塔和路线，但都没有形成足够清晰的上下元数据安全带；各进行一次单问题修正后通过。目标适配人工评分为木刻 25/25、剪纸 24/25，差异来自木刻更强的缩略图轮廓。这个失败只支持收紧 `field-journal` Profile，没有被扩大为所有交付类型的通用规则。

随后开展的 `n=3` Pilot 覆盖人物关系、产品静物和建筑交通：父女修风筝自动路由为针织书封，无品牌茶具自动路由为剪纸活动海报，雪山缆车自动路由为木刻旅行日志。三张结果均在首次编译生成中通过声明门禁，且更新后的 field-journal 安全带在新建筑样本上复现。由于样本为有意选择的合成照片且每类仅一张，这个 3/3 只能作为跨题材冒烟测试，不能估计真实生产成功率。

研究页面现采用追加式台账，原始 before/after、上游证据与后续层级各自保留。扩展 Skill 还新增 `score_review.py`：它不读取像素，而是根据场景和交付 Profile 检查人工 Review 是否覆盖全部门禁、状态和证据，再确定性汇总 pass/fail/unverified 与分数。缺门禁、额外门禁、非法状态或矛盾分数都会 fail-closed。

正式安装到用户 Codex Skills 目录后，Skill 又完成了一次全中文调用：中文请求、中文 Essence 与中文隐私约束由安装副本编译为 `seasonal-campaign → layered-paper → campaign-poster`，随后内置 ImageGen 首次生成通过。中文 Review 覆盖七项门禁，评分器返回 PASS 34/35；唯一扣分来自宽横幅裁切会损失部分底部叶形。这个测试证明中文输入链路可运行，不代表所有中文描述或真实产品照片都能达到相同结果。

为避免仅凭效果图判断，新增验证区为每个样例并列完整原始照片与处理结果：家庭宠物照料自动路由为有机针织，社区雨水花园自动路由为彩色玻璃，无品牌蜂蜜产品显式覆盖为陶瓷浮雕。三者均首次通过，Review 分别为 35/35、35/35、34/35；页面同时列出保留、转化和舍弃，便于判断是否真正重构而非表面滤镜。

## 这个仓库的意义

### 对设计工作

它把设计师常说的“抓重点、做减法、找隐喻、留呼吸、别太工整”转换为 Agent 可以重复读取的工作协议。价值不在某一张成图，而在不同人和不同任务可以共享同一套艺术指导语言。

### 对 Agent 工程

它展示了 Skill 适合承担的职责：语义分析、决策顺序、参考资料路由、工具调用和结果门禁。与把所有内容塞进一条超长 Prompt 相比，Skill 更容易维护、复用和迭代。

### 对生成式设计研究

它提供了一个小而清晰的研究对象：如何把隐性的视觉判断显式化，以及哪些约束真正提升了“重构感”而不损伤“辨识度”。如果增加数据集、盲评、消融和模型版本记录，可以发展为计算创意或人机协作研究。

## 能力边界与风险

1. **不是确定性程序**：同一输入可能得到不同构图、材质和文字质量。
2. **没有模型锁定**：`openai.yaml` 没有声明具体图像模型，宿主升级可能改变输出。
3. **没有自动量化**：55–60% 占比、三项结构变化和“不要像滤镜”都靠视觉判断。
4. **文字仍是风险点**：短标题成功率较高，但不能替代排版软件的精确文字。
5. **参考泄漏需要长期测试**：明确禁止复制不等于从统计上证明绝不复制。
6. **素材合规仍由使用者负责**：人物肖像、品牌标识、商业摄影与风格参考都需要合法来源。
7. **不是实物针织图纸**：输出表现的是针织美术，不提供针法、尺寸、纱线用量或可制造结构。

## 研究价值判断

| 目标 | 价值 | 原因 |
| --- | --- | --- |
| 学习 Codex Skill 结构 | 高 | 小型、完整、触发和参考路由清晰 |
| 学习图像 Prompt 编排 | 高 | 把取舍、概念、构图、材料和避免项分层 |
| 品牌视觉快速概念验证 | 中高 | 风格明确、留白适合封面和传播物料 |
| 批量商业生产 | 中 | 需要模板化、质检、版本与成本控制 |
| 底层图像算法研究 | 低 | 没有网络结构、训练代码或新损失函数 |
| 直接作为学术成果 | 低 | 缺少数据集、对照、消融和统计评价 |
