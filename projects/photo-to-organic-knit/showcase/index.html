MANUAL OVERRIDE24 / 25

“纸带适合更安静的编辑路线故事。”

材料层次更柔和、留白更自然，仍然是有效交付；但缩小后人物、路径和灯塔的对比略弱，因此在当前目标下只落后一分。

OBSERVED FAILURE → NARROW FIX

第一轮不是全过。

两张首轮结果都把画面铺满，无法稳定放置日志标题与坐标。Skill 没有无限重试，而是各做一次只针对安全区的修正；随后把证据写回 `field-journal` Profile。

DECISION

自动路线胜出，但人工覆盖仍然有效。

当前目标强调路线力量和缩略识别，所以木刻更合适；如果目标改成安静、现代的编辑封面，剪纸可能成为首选。这个结果支持“按目标路由”，而不是宣称某个效果永远最好。

10G / NON-PRODUCTION ACTION RUNBOOK

暂不进入生产，
现在具体做什么？

停止继续堆基础设施。当前阶段的动作是稳定地使用、记录失败、扩大样本和保留可复现证据；涉及真实身份、密钥托管、客户资产与公开发布的事项全部延期。

  1. 01
    GOAL LOCK确认目标、受众、交付、隐私和必须保留的锚点。

    信息不足就停下来澄清，不猜身份、数量或权限。

  2. 02
    ESSENCE写 retain / transform / discard 和核心视觉隐喻。

    只记录能从原图和目标中得到的证据。

  3. 03
    ROUTE & GENERATE编译场景、效果与交付，生成无字 Key Art。

    一次只修一个失败门禁；同一门禁两次仍失败就停止。

  4. 04
    REVIEW逐项记录人工证据，不允许分数凭空出现。

    任何必需门禁 fail 或 unverified，都不能进入发布层。

  5. 05
    LAYOUT选择 Sample 或 Approved 路线，放入准确 copy.json。

    文字溢出就改文案或换行，不无限缩字，也不交给生图模型。

  6. 06
    VERIFY检查版式；Approved 还必须验证 Manifest、签名、Trust 与 Audit。

    任一哈希、审批、签名或审计失败，立即冻结该次输出。

  7. 07
    RETAIN保存输入、输出、哈希、报告、边界和失败版本。

    私钥和未授权私有原图不得进入项目或发布包。

12 / HOW IT WORKS

五层协作，
只有一层出图。

把每一层的职责分开，才能理解它的意义，也能避免把优秀结果误认为仓库训练了模型。

  1. 01
    用户照片

    提供主体、关系、轮廓、运动与情绪。

    内容证据
  2. 02
    Codex 视觉理解

    识别方向、锚点，并完成 retain / transform / discard。

    语义决策
  3. 03
    Skill 艺术指导

    选择隐喻、设计装置、构图尺度、材料与避免项。

    规则编排
  4. 04
    ImageGen

    接收原图、风格参考和生产 Prompt，生成实际像素。

    外部模型
  5. 05
    检查与迭代

    验证辨识、转化、留白、材质和题字，一次只修一个问题。

    质量门禁
CONTENT ROLE

原照片不是版式模板

只保留定义身份的少数锚点。摄影透视、连续背景和次要纹理都可以被舍弃。

STYLE ROLE

参考图不是复制对象

只借用真实纤维、针脚、毛毡、边缘与光线质量，明确排除火车、桥梁和原题字。

AGENT ROLE

Prompt 是设计合同

必须说明选了什么、为什么变、怎样重构，以及什么结果即使漂亮也应该拒绝。

13 / WHY IT MATTERS

它把隐性审美，
变成共享语言。

仓库很小，但命中了生成式创作最难维护的一层：怎样让不同任务沿着同一种判断方式工作。

01

从形容词到决策

“温暖、手作、有设计感”被拆成取舍、隐喻、层级、留白、材料和瑕疵。

02

从滤镜到作者性

要求至少三项结构变化，让输出拥有新的视觉路径，而不是原图的针织复制品。

03

从一次 Prompt 到 Skill

团队可以版本化工作流、参考图和质量门禁，而不是在聊天记录里寻找灵感句子。

04

从成图到可研究对象

规则可以被消融、比较和评分，为计算创意与人机协作提供清晰实验单元。

BOUNDARY

值得研究，但别把它说成新模型。

  • 没有模型权重、训练数据或像素渲染代码
  • 构图比例和“不要像滤镜”仍靠视觉判断
  • 短标题不等于可替代专业排版
  • 一次成功案例不能证明批量稳定性
  • 生成针织美术不等于可制造针织图纸
