## 定位

Promise Wall 是一个可直接运行的 Three.js 交互作品，不是封装好 API 的 JavaScript 库。它把固定的承诺数据绘制成不同纸张，再将纸张作为弯曲的 Three.js 平面放到一面可浏览的 3D 墙上；DOM 负责导航、搜索、详情、编辑器和反馈。

上游仓库描述其由 Fable 5 开发，但仓库没有保存 Prompt、生成过程、迭代记录或评测，因此本研究只把“由 Fable 5 开发”视为来源描述，不把视觉结果反推成模型能力结论。

## 运行结构

```text
内存 store
  -> Canvas 生成纸张／照片文字与纹理
  -> CanvasTexture
  -> 弯曲 PlaneGeometry + 图钉／胶带／夹子
  -> Three.js 场景、光照、阴影与摄像机
  -> Raycaster 将指针映射回卡片或墙面
  -> DOM 面板完成搜索、详情、创建和反馈
```

### 1. 数据层

`index.html:1482–1874` 定义八个分类、八种纸张和二十条左右的初始内容。`P()` 为内容补全作者、旋转、宽度、互动计数、正文等默认字段。

`wallStateJSON()` 可以序列化 `store`，但它只是未来后端适配点。代码没有调用 Local Storage、IndexedDB、`fetch()` 或 WebSocket。

### 2. 程序化视觉层

`makePaperTexture()` 通过 Canvas 生成：

- 撕裂轮廓和透明 Alpha；
- 纸张颗粒、纤维、色斑和边缘暗化；
- 横线、方格和活页孔；
- Caveat 或 Cormorant Garamond 文字排版；
- 爱心、星形、枝叶和箭头涂鸦。

此外还有程序化照片、胶带、石墙和木纹。这里最可复用的不是某一张纹理，而是“数据驱动 Canvas 纹理工厂”的方法。

### 3. 3D 场景层

场景使用透视相机、半球光、方向光、点光、PCF 软阴影、ACES Filmic Tone Mapping 与雾。墙面是一张延伸到相机活动范围之外的大平面，底部增加木地板和踢脚线，避免看起来像孤立展板。

卡片使用 12×12 细分的 PlaneGeometry。`bendGeometry()` 直接修改顶点 Z 值制造纸张起伏；`makeAttach()` 生成图钉、胶带或长尾夹；`stackZ()` 根据附近卡片估算新的 Z 高度。

### 4. 交互层

- 指针拖动改变摄像机目标位置；
- 滚轮改变相机 Z 值；
- Raycaster 对 `pickables` 拾取；
- 悬停提高卡片位置和缩放；
- 选中后其他卡片变暗并移动镜头；
- 新建卡片先跟随指针，再通过墙面射线交点完成放置；
- 放置靠近屏幕边缘时自动平移摄像机。

### 5. DOM 产品层

DOM 提供搜索、分类、详情、最近添加、编辑弹窗和反馈 Toast。Three.js 对象通过 `Vector3.project(camera)` 将添加按钮等 HTML 元素投影到屏幕坐标，形成 DOM 与 WebGL 共用空间锚点的效果。

## 内部样例

固定数据包含健康、善意、学习、家庭、工作和自我成长等内容，并使用 Classic、Notebook、Graph、Blush、Lilac、Sage、Kraft、Handmade 八种纸张。附件包括图钉、胶带和夹子；部分内容使用程序化“山脊”和“海滩”照片卡。

这些样例共同验证：

1. 同一数据结构可以映射到不同纸张与附件；
2. Canvas 内容能够直接成为 3D 材质；
3. 2D 产品操作可以保持可读，同时利用 WebGL 建立空间记忆；
4. 新卡片可以从表单数据进入空间放置流程。

## 性能风险

当前数据量小，运行流畅不代表可扩展到大型社区：

- 每张卡片创建独立 512px CanvasTexture；
- 每张纸使用 169 个顶点，并启用投射／接收阴影；
- 每帧遍历所有卡片和子材质更新透明度；
- 没有视锥外业务级卸载、纹理图集、对象池、实例化或 LOD；
- renderer 像素比最高为 2，方向光阴影贴图为 2048×2048；
- CanvasTexture 和几何体没有生命周期释放路径。

因此它适合作为几十张卡片的体验样例，而不是已验证的千级内容引擎。

## 工程风险

- 根 `index.html` 共 3587 行，样式、数据、渲染和交互强耦合。
- `src/main.js` 和 `src/style.css` 仍是 Vite 默认模板，与实际入口不一致。
- Three.js 与 GSAP 由 CDN 加载，没有进入 npm 依赖和锁文件。
- 没有 README、测试、持续集成或错误监控。
- 没有 LICENSE。

## 研究结论

| 方向 | 价值 | 结论 |
| --- | --- | --- |
| Three.js 空间卡片 | 高 | 值得拆出模板 |
| Canvas 程序化纹理 | 高 | 最有迁移价值 |
| DOM/WebGL 混合 UI | 高 | 适合沉浸式产品研究 |
| 情绪化视觉设计 | 高 | 已形成完整氛围 |
| 社区产品能力 | 低 | 只有前端模拟 |
| 大规模性能 | 低 | 未验证 |
| 可维护工程结构 | 低 | 需要重构 |
| AI 生成工程样本 | 高 | 视觉完成度与仓库治理落差明显 |
