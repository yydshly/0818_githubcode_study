03 / INTERNAL SAMPLES

原版内部样例说明了什么？

不是素材数量，而是同一内容系统如何形成不同触感和状态。

八种纸张

撕纸、笔记本、方格、粉色、紫色、绿色、牛皮纸和手工纸，共享同一个 Canvas 绘制管线。

三种附件

图钉、胶带和长尾夹是独立 3D 几何，不是画进纸张里的装饰。

照片卡

山脊和海滩样例仍由 Canvas 程序化生成，用于验证混合内容，不代表上传能力。

空间反馈

悬停抬升、选中聚焦、背景变暗和放置回弹共同建立“摸到纸”的感觉。

07 / PRODUCTION ROUTE

从漂亮 Demo 到可信产品。

  1. PHASE 0

    工程整理

    拆分单文件、锁定依赖、清理默认模板、建立类型和测试。

  2. PHASE 1

    可信单机版

    本地持久化、迁移、导入导出、编辑撤销和列表 fallback。

  3. PHASE 2

    真实在线产品

    身份、数据库、同步、审核、隐私、上传和可观测性。

  4. PHASE 3

    选择一个场景

    关系、时间、导览或 AI 四选一，用真实任务指标验证。
