# Projects

`projects/` 用于存放适合在本仓库内维护的轻量研究材料，例如最小复现、概念验证、基准脚本和补充示例。

## 目录约定

每个项目使用独立目录：

```text
projects/
└── project-slug/
    ├── README.md       # 目标、上游版本、运行方法与结论
    ├── src/            # 实验源码（按需）
    └── tests/          # 验证用例（按需）
```

如果子项目需要独立依赖、CI、版本管理或在线部署，优先创建独立 GitHub 仓库，并从根目录 `README.md` 链接过去。

## 最低记录要求

每个项目至少应说明：

- 上游仓库与固定的 commit/tag；
- 研究目标和当前状态；
- 安装、运行与验证步骤；
- 相对上游所做的修改；
- 第三方许可证与署名要求。
