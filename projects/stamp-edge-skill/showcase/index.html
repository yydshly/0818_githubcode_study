03 / THREE MODES

上游真正提供的
三种单图效果。

效果差异不是滤镜，而是输出合同：默认真透明、可选白色纸边、或直接压平为浅灰白成品背景。

01 / DEFAULT

无白边 · 真透明

画面抵达齿孔边；孔洞、外部和投影空间保留 Alpha。

stamp_effect.py input output.png

白色纸边 · 真透明

04 / ORIGINAL COLLECTION FEATURE

原始库的第二项能力：
把多张邮票排成合集。

`stamp_sheet.py` 会把图片等比缩放到统一列宽，按高度从大到小排序，再逐张放入当前最矮的列。它追求列高平衡，因此会改变输入顺序。

1统一列宽
2高度降序
3放入最矮列
4按 Alpha 合成
05 / MECHANISM

视觉更丰富，
算法仍然很小。

Agent 负责识别请求和选择模式；Pillow 负责蒙版、合成与排版。没有生成模型参与邮票处理。

  1. 01

    灰度蒙版

    先建立完整矩形 Alpha。

  2. 02

    四边减圆

    圆心贴边，留下半圆齿孔。

  3. 03

    图像合成

    可选白边后覆盖新蒙版。

  4. 04

    柔和投影

    两次模糊和轻微位置偏移。

  5. 05

    输出或合集

    RGBA 单图，或 RGB 瀑布流。

已验证边界

外部与齿孔透明成立，但输入图片内部原有 Alpha 会被新蒙版覆盖。透明素材往返需要改为 Alpha 相乘。

INPUT CENTER α 0 → OUTPUT α 255

06 / IMPLEMENTED EXTENSIONS

邮票之后，
六个 preset 已经可运行。

沿用“确定性脚本 + Agent 路由”的结构，新扩展全部使用 Pillow，由同一个 CLI 调用；这里展示的不是规划图，而是实际输出。

POLAROID

拍立得

暖白纸框、加厚底边和可选题注。

--preset polaroid
TORN PAPER

撕纸

可复现的不规则 Alpha 纸边与柔和投影。

--preset torn-paper
FILM FRAME

胶片

黑色片框、上下透明齿孔、帧号。

--preset film-frame
TICKET

票券

横向裁切、侧边缺口、编号和票根区。

--preset ticket
RISO PRINT

Riso 印刷

蓝红双色、错版边缘、网点和纸色底。

--preset riso-print
STICKER OUTLINE

轮廓贴纸

围绕已有 Alpha 扩展白色轮廓；不冒充自动抠图。

--preset sticker-outline

07 / RESEARCH CLOSURE

本次研究到这里，
已经足够。

我们已经确认上游的真实能力与限制，完成高质量场景复现、合集展示和六个确定性扩展。继续把它产品化的边际收益已经不高，因此当前项目正式收口，不再继续开发 `stamp-v2`。

COMPLETED / 已完成
  • 固定并审阅上游 v1.2.0
  • 复现三种单图模式与两种合集
  • 完成六类真实内容场景
  • 实现六个确定性扩展 preset
  • 沉淀 Skill、文档、测试与浏览器证据
INTENTIONALLY STOPPED / 刻意不继续
  • 不修改上游为 `stamp-v2`
  • 不继续堆叠相似滤镜
  • 不建设完整批量生产产品
  • 不引入主体分割或生成模型依赖
  • 不进行全局安装、发布或商业化包装
IF REOPENED LATER

后期如果重启，只建议沿四个方向继续。
