# Punk IP Illustrations：使用场景与扩展路线

## 适合使用

| 场景 | 输入 | 期望产物 | 为什么适合 |
| --- | --- | --- | --- |
| 公众号与博客长文 | 完整文章或 Markdown | 1—8 张统一角色正文插图 | 需要稳定作者形象和明确插入位置 |
| 教程与 SOP | 步骤、方法、工作流 | 3—5 节点流程拆解图 | 同一角色可以在多个步骤承担不同动作 |
| 观点与社媒帖子 | 单个判断或短帖 | 一张核心动作图 | 一个物理关系即可承载反直觉观点 |
| 顾问、讲师与创始人内容 | 已确认个人 IP + 系列文章 | 统一视觉栏目 | 人物身份和固定服装可重复使用 |
| 团队知识内容 | 多个已确认角色 | 按作者或栏目切换角色 | 注册表支持列出、激活和解析多个角色 |
| 多栏目品牌内容 | 一个或多个角色 + 不同主题 | 统一人物、不同认知锚点 | 角色身份与文章场景分离 |

## 不适合直接使用

- 需要像素级连续性的漫画、动画分镜或商业角色设定生产。
- 写实人像摄影和必须精确还原真人的法律、证件用途。
- 财务图表、数据仪表盘和高密度复杂信息图。
- 必须保证中文零错字的海报、课程页和商业广告。
- 需要自由切换大量品牌风格的通用插图平台。
- 没有参考图生成能力、文件系统或完整文章访问能力的宿主。

## 第一层：工程可靠性扩展

这些方向不改变产品定位，应优先完成。

### 1. 自动一致性评估

对每张候选图计算角色参考与生成图的人脸、发型、服装色、配件位置和身体比例相似度，输出分项分数，不再只依赖 Agent 主观检查。风格化人脸不宜只依赖 ArcFace，可组合 DINO/CLIP 特征、分割色块和人工评分。

### 2. 结构化图片计划

将认知锚点保存为 JSON：原文证据、核心判断、模式、角色动作、物件、文字、插入锚点和状态。这样可以重跑单张、比较模型和审计“为什么生成这张图”。

### 3. 确定性文字后处理

优先生成无字底图，再使用 SVG/Canvas/Pillow 叠加短标签。把语义生成与精确排版分离，可以显著降低中文错字和布局漂移。

### 4. 可观测重试

记录模型、参考图版本、提示版本、生成耗时、成本、失败原因和重试差异。当前“最多两次重试”是规则，但没有可比较的运行记录。

### 5. 测试与安全

为注册脚本增加路径、损坏 JSON、版本竞争和非法状态测试；为图片文件增加 MIME、尺寸与体积检查；为人物照片建立清理与保留策略。

## 第二层：产品工作台扩展

### 1. 角色工作室

用可视化界面管理草稿、确认版本、身份规范、多个角色和历史修订，并提供前后对比与回滚。

### 2. 文章配图审核台

左侧显示文章与插入锚点，右侧显示图片计划和候选图；用户可改模式、动作、物件或插入位置，再局部重生成。

### 3. 批量与栏目模板

为公众号、Newsletter、知识库和课程建立画幅、数量、留白、文字密度与导出目录模板，但仍保持角色身份与风格合同分离。

### 4. 可插拔风格包

将“复古彩色扁平 3D”从唯一风格变为一个风格插件。每个插件定义画面语言、禁用项、文本规则、评估规则和示例，而不修改角色包。

风格扩展应按身份保留风险逐步推进：半写实编辑与扁平 3D 变体风险较低；极简编辑、线稿和水彩会减少或扰动五官信息，属于中风险；Q 版、像素、剪纸、漫画和抽象实验会重构身体或面部比例，属于高风险。每个风格包至少需要画面合同、视觉语言、身份规则、禁用项和评估规则，不能只在通用提示后追加一句风格形容词。

### 5. 团队审核与权利管理

增加照片授权记录、角色所有者、可用渠道、到期时间和发布审批。个人 IP 一旦进入团队生产，权利边界比提示词本身更重要。

## 第三层：研究型扩展

### 1. 角色一致性基准

建立跨动作、角度、遮挡、物件、情绪和多角色场景的数据集，比较不同参考图策略：仅干净参考、干净参考 + 四视图、多参考图、角色 LoRA/ID adapter 等。

### 2. 文章语义覆盖率

评价生成的图片集合是否覆盖文章的总判断、关键机制、转折与行动结论，同时避免重复。可以结合人工标注、语义相似度和“删除一张后理解是否下降”的消融实验。

### 3. 跨模型可移植性

同一结构化计划分别运行在多种图像模型，比较身份一致、语义正确、文字准确、风格符合、成本和耗时，从而判断 Skill 规则是否真正独立于模型。

### 4. 长期身份记忆漂移

追踪同一角色经过 10、50、100 篇文章后是否发生服装、脸型和配件漂移；比较“每次回到原始确认参考”与“用上一张生成图继续参考”的误差累积。

### 5. 人工确认点优化

当前只有角色确认是强制暂停。可实验图片计划预览、低置信度插图审核和高风险发布审核是否能在不显著增加操作成本的情况下提高质量。

## 从自有实演得到的扩展信号

本研究的“小岚”流程说明，设定板 + 干净参考图足以支撑一次清晰的四节点场景，但也暴露出下一步应该测量的变量：正侧背视角是否同样稳定、挎包左右方向是否漂移、角色重复出现四次时五官差异多大，以及换模型或间隔多日重跑后是否仍可识别。建议把本次四张资产作为基线样本，后续新增候选图时保留模型、参考组合、提示版本和人工评分，而不是只保存最终最好的一张。

## 推荐优先级

```text
P0 结构化图片计划 + 运行记录
  ↓
P1 一致性评分 + 无字底图确定性排版
  ↓
P2 文章审核台 + 可插拔风格包
  ↓
P3 跨模型基准 + 长期漂移研究
```

这条路线先让现有工作流可测、可复现，再扩展界面和风格，最后进入模型与长期记忆研究。
