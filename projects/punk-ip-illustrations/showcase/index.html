RESEARCH 08 / CHARACTER CONSISTENCY

一个角色，
持续进入每一篇文章。

它不是一个新的图像模型。它把人物照片、角色确认、身份参考、文章理解和图片交付编排成一条可重复使用的 Agent 工作流。

本质是形象一致，
价值在持续使用。

固定的是角色身份；变化的是文章观点、动作和物件。仓库真正增加的，是确认门、角色包和跨文章复用规则。

必须稳定

  • 身体比例与年龄感

允许变化

  • 视线与轻微表情

GUIDE A / HOW TO USE IT

把内容交给 AI，
不是把场景塞进原图。

原始图只负责回答“谁”；文章、目标或大纲负责回答“表达什么”。Skill 把两类输入编排成图片计划，再由可用的图像模型生成最终像素。

它们不是三个不同功能，而是同一条工作流的不同输入深度。

GUIDE B / STYLE EXPANSION

身份可以固定，
风格可以插拔。

上游当前只定义“复古彩色扁平 3D”这一套视觉合同。多风格不是仓库已经完成的功能，而是建立在角色包与文章计划之上的自然扩展方向。
STABLE角色身份脸、发型、眼镜、服装、配件
＋
DYNAMIC文章语义观点、动作、物件、流程关系
＋
PLUGGABLE视觉风格包线条、材质、色彩、光影、构图规则
CURRENT / UPSTREAM

一套固定风格，减少生产变量

  • 16:9 横版、纯白背景
  • 复古扁平 3D、圆润几何
  • 主体约占 55%—65%
  • 1—3 个物件、3—5 个主色
这是已实现规则
→
EXTENSION / PROPOSED

多套风格包，共用同一个确认角色

  • 每套风格拥有独立视觉合同
  • 身份锚点不随风格切换
  • 文章计划不与渲染风格耦合
  • 每种风格单独评估身份漂移
这是本研究建议，不是上游现状
STYLE FAMILIES

可扩展风格与身份保留风险

越强烈地改变五官和身体比例，越需要额外参考与人工复核。

低风险

半写实编辑

保留面部结构和人体比例，只改变光影、材质与背景语言。

适合：专业文章、个人品牌
低风险

扁平 3D 变体

在现有风格上改变色板、材质和几何细节，迁移成本最低。

适合：教程、SOP、知识栏目
中风险

极简编辑插画

减少面部细节，身份更多依赖发型、眼镜、服装和配件。

适合：观点、商业内容
中风险

线稿与水彩

笔触和轮廓波动更大，需要锁定五官比例与颜色锚点。

适合：随笔、故事、课程
高风险

Q 版、像素与剪纸

身体与五官比例被强烈重构，必须依赖标志性外观识别。

适合：轻内容、贴纸、栏目符号
高风险

漫画与抽象实验

夸张动作和镜头会放大侧脸、遮挡与配件镜像问题。

适合：叙事测试、视觉实验
STYLE PACK CONTRACT

真正可用的风格扩展，不只是追加一句“改成水彩”。

每个风格包都应把视觉选择变成可检查的合同，并与人物身份规范分开保存。

  1. 01画面合同画幅、背景、主体占比、留白与物件数量
  2. 02视觉语言线条、材质、色板、阴影、透视和细节密度
  3. 03身份规则必须保留与允许风格化的外观特征
  4. 04禁用项完整房间、大段文字、品牌 Logo 或竞争隐喻
  5. 05评估规则身份相似、语义正确、风格符合、文字准确

准确描述当前仓库：固定角色 + 固定风格 + 动态文章场景

扩展目标固定角色 + 可选风格包 + 动态文章场景

01 / CAPABILITY ANATOMY

三层能力，
不要混成一个“AI 魔法”。

切换角色层、文章层和交付层，查看每一层的输入、确定性实现与外部依赖。
01
PHOTO → REUSABLE CHARACTER

把一次照片输入编译成角色资产包

照片是唯一身份来源。Agent 生成角色设定板、干净单人物参考图和人物规范，再由注册脚本写入本地角色包。草稿不能进入文章生产。

确定性
目录、manifest、版本、状态
生成式
四视图、干净参考、身份提炼
人工门
明确说“确认”才可激活
02
FULL TEXT → COGNITIVE ANCHORS

从完整文章选择真正值得可视化的关系

Agent 不按段落平均配图，而是寻找总判断、易误解机制、逻辑转折、冲突和行动结论。每个锚点再选择“流程拆解”或“核心动作”。

数量
短观点 1 张，长文最多约 8 张
模式
流程拆解 / 核心动作
限制
依赖 LLM 判断，没有评分器
03
PLAN → FILES → ARTICLE

逐张生成、检查、命名并报告插入位置

每个认知锚点独立生成一张 PNG；失败时只修一个主要问题，最多两次针对性重试。默认不修改文章，只有用户明确要求才写回 Markdown。

输出
绝对路径、用途、插入锚点
版本
同名文件使用 -v2 / -v3
降级
无图像工具时只交付提示与计划

02 / THE OPERATING LOOP

确认角色只暂停一次，
后续文章自动向前走。

这条链路把高风险的身份确认放在前面，把可重复的文章配图留给自动执行。
  1. 01
    IDENTITY SOURCE

    上传人物照片

    提取可观察的脸型、发型、服装和配件，不猜测敏感属性。

  2. 02
    CHARACTER DRAFT

    生成角色草稿

    主角色 + 四视图、干净参考图、人物规范，状态仍是 draft。

  3. 03
    HUMAN GATE

    修改或明确确认

    这是唯一必须停下来的环节。未确认角色不能用于文章配图。

  4. 04
    ACTIVE MEMORY

    激活当前角色

    注册表只解析 confirmed 角色；后续不再需要重复上传照片。

  5. 05
    ARTICLE PLANNING

    读取全文并选择锚点

    决定图片数量、表现模式、动作、物件和建议插入位置。

  6. 06
    GENERATE & DELIVER

    逐张生成与交付

    检查语义、身份、留白和文字，保存版本并报告实际路径。

NEW / REVISEDdraft不可激活 · 不可配图
用户明确确认 →
APPROVEDconfirmed可激活 · 可跨文章复用
选择当前角色 →
POINTERcurrent解析为绝对资产路径

03 / UPSTREAM EVIDENCE · RETAINED

上游公开样张，
继续保留作对照。

自有实演没有替换这些证据。以下四张图仍来自固定上游 `docs/images/`，用于对照其“流程拆解 / 核心动作”两种模式。角色源设定资产受单独许可约束，本展厅不直接展示或复制。
MODE A

流程拆解

适合步骤、方法、教程和工作流。一个角色在 3—5 个节点承担不同动作。

MODE B

核心动作

适合观点、冲突和反直觉关系。一个人物、一个动作、一个可见结果。

固定画面合同16:9 横版 · 纯白页面 · 主体 55%—65% · 1—3 个主要物件 · 3—5 个场景主色

明确不做封面海报 · 复杂信息图 · 完整空间背景 · 大段文字 · 多个竞争隐喻

04 / WHERE IT FITS

不是所有视觉任务，
都需要一个固定人物。

按内容、组织或品牌筛选场景；红色边界卡说明何时不该使用这套工作流。
CONTENT / LONGFORM

公众号与博客长文

从完整文章选择 1—8 个认知锚点，让作者 IP 持续出现在系列内容中。

交付：正文插图 + 建议插入位置
CONTENT / PROCESS

教程、SOP 与工作流

把输入到输出压缩为 3—5 个节点，同一角色在各节点执行不同动作。

交付：流程拆解图
CONTENT / OPINION

观点与社媒帖子

将反直觉判断压缩成一个人物与一个物理关系，减少装饰性配图。

交付：核心动作图
BRAND / EXPERT

顾问、讲师与创始人

固定人物身份、服装和配件，建立跨文章可识别的内容栏目。

价值：个人 IP 的视觉连续性
TEAM / AUTHORS

团队作者与知识栏目

为不同成员创建确认角色，按文章作者切换当前角色。

价值：多角色注册与激活
BRAND / SERIES

多栏目系列内容

保持人物身份不变，让动作和物件随栏目主题变化，形成统一视觉记忆。

价值：身份与场景解耦
AVOID / PRECISION

像素级连续漫画

参考图不能保证跨镜头、遮挡和复杂动作的精确连续性，需要更强角色模型或制作管线。

原因：身份一致性没有算法保证
AVOID / DATA

数据图表与复杂信息图

这套视觉合同刻意限制为一个关系和少量物件，不适合精确数据表达。

原因：表达密度与任务冲突
AVOID / TYPOGRAPHY

必须零错字的商业海报

图像模型内生文字仍可能错误，应改用无字底图与确定性排版。

原因：文本不是确定性输出

当前显示 9 个场景

05 / EXTENSION ROADMAP

先让它可测，
再把它做大。

扩展分成工程可靠性、产品工作台和研究验证三层。它们是本研究建议，不是上游已实现功能。
MAKE IT MEASURABLE

把“看起来像”变成可追踪的质量数据

不改变 Skill 定位，先补足稳定性、文字与运行记录。

  1. 01

    结构化图片计划

    保存原文证据、锚点、模式、动作、物件、插入位置和状态。

    最高优先
  2. 02

    角色一致性评分

    组合视觉特征、服装色和人工评分，检测脸、发型与配件漂移。

    核心指标
  3. 03

    确定性文字排版

    先生成无字底图，再用 SVG/Canvas/Pillow 叠加准确标签。

    立即可做
  4. 04

    运行观测与测试

    记录模型、参考图版本、成本、耗时、失败原因和重试差异。

    生产基础
MAKE IT OPERABLE

把命令行式 Skill 变成可审核的内容工作台

让角色、文章锚点和图片候选在同一界面可见。

  1. 01

    角色工作室

    草稿、确认、版本对比、回滚、多角色和身份规范可视化管理。

    身份中心
  2. 02

    文章配图审核台

    文章段落、认知锚点、候选图和插入位置并排审核并局部重生成。

    主闭环
  3. 03

    可插拔风格包

    角色身份保持独立，风格插件分别定义画面、文字与评估合同。

    扩展表面
  4. 04

    权利与团队审批

    记录照片授权、角色所有者、可用渠道、期限和发布审批。

    团队边界
MAKE IT TESTABLE

验证工作流是否真的跨模型、跨时间保持有效

从主观样张展示升级为可重复的实验与消融。

  1. 01

    角色一致性基准

    覆盖动作、角度、遮挡、情绪和多角色，比较不同参考图策略。

    视觉基准
  2. 02

    文章语义覆盖率

    评价图片集合是否覆盖总判断、机制、转折和行动结论且不重复。

    规划基准
  3. 03

    跨模型可移植性

    用同一图片计划比较身份、语义、文字、成本和耗时。

    系统基准
  4. 04

    长期身份漂移

    追踪同一角色经过 10、50、100 篇文章后的误差累积。

    记忆研究

06 / RESEARCH VERDICT

值得研究，
但研究对象不是画图算法。

它最有价值的部分，是 Agent 工作流、人在回路和跨任务角色记忆；模型创新与生产成熟度仍有限。
Agent Skill 结构8.0

阶段路由、按需读参考、失败降级完整。

人在回路设计8.5

把唯一强制确认放在身份定稿点。

长期角色记忆7.5

角色包简单、清楚、可跨任务解析。

图像算法创新2.0

没有训练、推理或一致性算法。

适合研究角色一致性工作流 · 内容语义到视觉规划 · Agent 本地状态 · 人工确认点
