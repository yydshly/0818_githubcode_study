# 可扩展方向与使用场景

## 现有扩展接口

### 1. 新增 Style

上游已经定义最小风格合同：

```yaml
style_id:
style_name:
concept:
medium:
line_language:
color_language:
edge_behavior:
texture:
human_rendering:
typography:
micro_graphics:
whitespace_behavior:
avoid:
```

新增风格应改变视觉语言，而不是只增加颜色或滤镜名。每个 Style 仍然服从全局的编辑感、克制、大留白和事实完整性。

### 2. 新增 Preset

Preset 负责把多个参数组合成稳定用途。例如可增加：

- `museum_object_note`：器物照片 → 标本页 + 展签引用；
- `family_micro_archive`：家庭瞬间 → 小照片 + 极简线稿；
- `architectural_field_note`：建筑 → 结构轴线 + 材料采样；
- `food_origin_card`：食物 → 材质标本 + 克制来源注记；
- `brand_memory_keyart`：品牌授权照片 → 无字主视觉底图。

Preset 应说明适用输入、禁用条件和失败降级策略，而不只是保存一组默认值。

### 3. 新增场景路由

在 `photo / text / mixed` 之后继续判断交付用途：封面、Story、邀请函、展签、社媒、相册或品牌主视觉。用途路由可以自动选择画幅、安全区、文字密度和是否保留原图。

### 4. 新增确定性辅助工具

这是最值得优先扩展的方向：

- 日期与农历计算器：让节日检测不依赖 LLM 心算。
- OCR 检查器：发现编号、中文原句和禁用文字错误。
- 网格/布局检查：验证 2×2、2×3、3×3 数量和阅读顺序。
- 分割工具：为分层贴纸提供真实 Alpha，而不是完全依赖生成模型重画边缘。
- 色板提取：从原图稳定导出 3–6 色供 Prompt 使用。
- 生成清单：保存模型、输入哈希、Prompt、输出、重试原因和最终选择。

这些工具不会取代视觉判断，但会把“必须精确”的部分从概率生成移到可验证程序。

### 5. 新增质量门禁

可将当前人工清单拆成半自动信号：

- 人数与主体重复检测；
- OCR 精确匹配；
- 留白比例估算；
- 主体占画面积；
- 色彩数量和饱和度；
- 预览格数量；
- 原图与成品的身份/构图相似度。

门禁只负责暴露风险，最终美学仍需人工判断。

## 七个产品化研究模块

下面七个方向不是“再增加七种滤镜”，而是把单图转译扩展为完整的记忆采集、编辑、交付和再使用系统。展厅中的交互是产品结构原型；除上游已有的 `mixed`、Preset、Display 和 Style 能力外，不代表仓库已经实现多图编排、分层文件、动画导出或语音识别。

### 1. 多照片叙事

**目标：** 把照片之间的时间、空间和情绪关系编辑出来，让输出具有开场、推进、停顿和收束。

**输入：** 3–12 张照片，可选拍摄时间、地点、用户原句和交付用途。

**处理：**

1. 读取时间顺序和基础元数据，但不擅自纠正用户事实。
2. 识别重复照片、主图、环境图、人物图和细节图。
3. 建立 3–6 个章节角色，例如抵达、路径、人物、细节和余韵。
4. 锁定统一色板、页边距、文字层级和抽象程度。
5. 为每一页分配一个视觉任务，避免每页都是相同拼贴。

**成品效果：** 四页视觉日记、折页小志、活动回顾长图、家庭年度档案或可继续排版的章节草案。第一页通常建立地点，第二页交代路径，第三页聚焦人物或关键物件，最后一页用一句原话或视觉隐喻收束。

**新增能力：** 多图去重与排序、跨图人物一致性、叙事分镜、系列版式和批量质量检查。

**边界：** 不伪造照片之间并不存在的事件；时间顺序不确定时必须保留“未确认”状态。

### 2. 混合记忆材料

**目标：** 保存一次经历的上下文，让照片、票据、手写、收据、日期和物件都保留各自的证据身份。

**输入：** 照片、扫描票根、收据、手写文字、用户确认的地点/日期，以及可选实物照片。

**处理：** 将材料分成三层：事实层负责日期、地点和原句；情绪层负责颜色、节奏和隐喻；装饰层只负责低强度微图形。OCR 结果必须允许人工校正，缺失字段不自动补写。

**成品效果：** 旅行档案页、家庭记忆盒、展览记录、收藏卡或数字纪念板。画面中照片仍像照片，票据仍能被识别为票据，手写仍被标记为用户原句，不把所有材料重绘成同一种假复古质感。

**新增能力：** OCR、来源标签、事实字段校验、透明素材提取、材料层级和可追溯清单。

**边界：** 真实票号、经纬度、机构印章和日期不得由生成模型虚构。

### 3. 时间与情绪转译

**目标：** 让用户用“时间距离”和“情绪强度”控制记忆语气，而不必理解水彩、极简抽象等风格术语。

**输入：** 原始照片、时间距离（刚刚发生到很久以前）和情绪强度（安静到强烈）。

**处理映射：**

| 控制量 | 低值 | 高值 |
| --- | --- | --- |
| 时间距离 | 保留地点、人物、主要光线与较多细节 | 减少细节、边缘和事实复述，转向色彩与隐喻 |
| 情绪强度 | 低饱和、主体较小、语气克制 | 强调色更集中、主体尺度增大、视觉张力更明显 |

**成品效果：** 同一张照片可以得到“当下版”“余温版”和“远忆版”。它们不是简单增加模糊，而是同时改变信息保留、留白、抽象度、颜色关系和文字距离。

**新增能力：** 语义滑杆到 Prompt 参数的映射表、强度上下限、可解释反馈和重新生成记录。

**边界：** 情绪是用户提供的编辑意图，不应由系统从人脸或身份特征中擅自推断。

### 4. 可编辑的分层成品

**目标：** 把不可修改的合成图变成设计师可以接管的资产结构。

**输入：** 原图、真实分割结果、转译结果、版式参数、正式标题和颜色/字体规范。

**建议图层：**

1. 纸张或透明背景；
2. 原始照片引用；
3. 主体、环境或贴纸转译层；
4. 确定性文字层；
5. 微图形、编号和辅助标记。

**成品效果：** PNG/SVG 图层包、PSD/Figma 可编辑结构或代码模板。用户可以隐藏某一层、替换正式文字、调整主体位置或输出不同画幅，而不必重新让模型生成整张图。

**新增能力：** 分割与 Alpha、图层命名、锚点坐标、字体排版、资产打包和导出校验。

**边界：** 当前上游只约束视觉生成，不输出真实可编辑文件；展厅图层开关演示的是目标行为，不是现有导出能力。

### 5. 系列化视觉系统

**目标：** 让多张不同内容的作品仍然具有共同身份，从“单张好看”升级为可持续使用的个人或品牌系列。

**输入：** 已授权素材、色板、字体、Logo 规则、边距、图片比例、编号和渠道规格。

**处理：** 锁定设计 token，建立方卡、竖版和横版模板；允许照片内容和局部构图变化，但颜色角色、标题层级、编号位置、留白比例和品牌安全区保持一致。

**成品效果：** 月度旅行卡、活动系列海报、专栏题图、城市记忆系列、年度影集或品牌活动全渠道底图。

**新增能力：** token 文件、模板版本、跨图一致性评分、批量变体、审批与 DAM 接口。

**边界：** Prompt 不能替代字体授权、品牌审批和批量质检；商业生产必须保留人工终审。

### 6. 动态与交互记忆

**目标：** 把“现实如何成为记忆”的过程本身变成叙事。

**输入：** 一张原图或照片序列，以及现实、选择、重组、余韵四阶段脚本。

**处理：** 第一阶段完整显示现实；第二阶段突出要保留的线索；第三阶段淡出非核心信息并重组主体；最后停留在记忆成品和一句短文字。网页可以使用 CSS/Canvas，成片则需要视频渲染和音画时间线。

**成品效果：** 5–10 秒动态纪念卡、滚动揭示网页、展览屏幕、活动大屏或社交短视频。运动用于解释状态变化，不只是让元素漂浮。

**新增能力：** 时间线、暂停/复位、关键帧导出、视频编码、性能预算和 reduced-motion 回退。

**边界：** 开启减少动态偏好时应直接呈现最终状态；核心内容不能依赖动画才可理解。

### 7. 声音与文字输入

**目标：** 保存人的说话方式、原句和情绪线索，让没有照片或照片不足的经历也能形成视觉档案。

**输入：** 语音日记、采访、长辈口述、会议片段或用户直接输入的一段文字。

**处理：**

```text
声音 / 文字
→ 转写与用户校对
→ 区分事实、原句、情绪和意象
→ 选择一个视觉隐喻
→ 与照片或纯文字版式组合
→ 确定性排版与人工审核
```

**成品效果：** 口述档案卡、声音明信片、采访章节、家庭史页面或带字幕的动态记忆。系统应保留一条准确原句，再以路径、线、容器或空间关系承担视觉隐喻。

**新增能力：** 录音授权、语音识别、说话人分离、转写校对、音频存储、隐私权限和字幕排版。

**边界：** 不从声音擅自判断身份、健康或敏感属性；未经确认的转写不能作为事实发布。

## 模块之间的组合

七个模块可以形成逐步升级的产品链路：

```text
多照片 / 混合材料 / 声音文字
→ 事实与情绪整理
→ 时间与情绪转译
→ 系列规则编排
→ 可编辑分层交付
→ 静态、动态或交互发布
```

建议先实现“多照片叙事 + 混合材料 + 可编辑分层”的最小闭环；声音、动态和品牌批量生产涉及额外隐私、性能与治理成本，应在核心编辑模型稳定后再接入。

## 可使用场景

### 旅行与城市记忆

**输入：** 山野、街道、海边、建筑、旅伴照片。  
**输出：** 旅行记忆页、地图札记、展览票、邮票、纪念封。  
**价值：** 把普通照片转成有编辑层级的个人档案，而不是套旅行滤镜。

### 人像与日常纪念

**输入：** 自拍、家人、宠物、生活瞬间。  
**输出：** 角落胶带照片、线稿水彩、圆润粗线、小型视觉岛。  
**注意：** 不适合高精度肖像修复或证件照；需严格保持人数、姿态和身份。

### 建筑、空间与设计观察

**输入：** 建筑立面、室内、公共空间、产品结构。  
**输出：** 结构解构、档案卡、长虹玻璃、展签引用。  
**价值：** 将轴线、透视、材料和光影提炼成研究封面或田野笔记。

### 食物、花草和器物

**输入：** 咖啡、餐桌、植物、工艺品、收藏物。  
**输出：** 标本页、材料采样、档案卡和小型色彩研究。  
**价值：** 适合菜单概念、展陈提案、品牌情绪板和个人收藏记录。

### 编辑出版与内容封面

**输入：** 已授权照片、文章主题、项目概念。  
**输出：** 杂志跨页、章节页、研究报告封面、专栏题图。  
**建议：** 生成无字或短字底图，正式标题与长文案放到 Figma、InDesign 或代码排版层。

### 一句话与概念卡

**输入：** 概念、标题、短句。  
**输出：** 原句 + 一个器物、路径、开关、容器或色块关系。  
**价值：** 适合演讲章节页、研究结论卡、社媒观点卡和团队复盘材料。

### 节日与纪念节点

**输入：** 与节日相关或同期的照片。  
**输出：** 基础风格上增加一个点缀色或一个符号。  
**边界：** 不应自动虚构情侣、家庭、服装、地点或拍摄日期；商业促销不适合沿用默认的极简节日层。

### 品牌概念与活动提案

**输入：** 已授权的产品、创始人、空间、地标或活动照片。  
**输出：** 主视觉方向、邀请函底图、品牌档案页和系列情绪提案。  
**边界：** 当前 Skill 更适合概念验证，不包含 Logo 安全区、品牌色锁定、审批、批量变体或 DAM。

## 不适合的场景

- 电商商品主图、精确抠图和像素级合成。
- 证件照、肖像修复、身份敏感人脸编辑。
- 数据图表、复杂信息图和长文排版。
- 需要精确 GIS、票号、机构印章或官方文件真实性的内容。
- 大规模无人工审核的批量品牌生产。
- 需要跨模型完全一致输出的确定性流水线。

## 推荐的扩展优先级

### A. 可复现

保存输入、配置、完整 Prompt、模型版本、输出与失败版本；为每次选号建立可追踪记录。

### B. 可验证

先实现日期、OCR、网格和留白检查，再考虑增加更多风格。当前最明显风险是文字、计数和复杂组合约束。

### C. 可编辑

让原图、贴纸层、背景、文字和微图形分层输出；正式文字走确定性排版。

### D. 可生产

增加品牌预设、权限与素材来源、批量变体、审批、成本记录、版本回退和 DAM 接口。

### E. 可研究

建立跨人像、建筑、旅行、食物与文本的固定样本集，记录首次通过率、重试原因、人工选择和不同图像模型的表现。这里的重点是稳定性研究，不需要把 Skill 开关测试当作前提。
