# 可扩展方向与使用场景

## 现有扩展接口

### 1. 新增 Style

上游已经定义最小风格合同：

```yaml
style_id:
style_name:
concept:
medium:
line_language:
color_language:
edge_behavior:
texture:
human_rendering:
typography:
micro_graphics:
whitespace_behavior:
avoid:
```

新增风格应改变视觉语言，而不是只增加颜色或滤镜名。每个 Style 仍然服从全局的编辑感、克制、大留白和事实完整性。

### 2. 新增 Preset

Preset 负责把多个参数组合成稳定用途。例如可增加：

- `museum_object_note`：器物照片 → 标本页 + 展签引用；
- `family_micro_archive`：家庭瞬间 → 小照片 + 极简线稿；
- `architectural_field_note`：建筑 → 结构轴线 + 材料采样；
- `food_origin_card`：食物 → 材质标本 + 克制来源注记；
- `brand_memory_keyart`：品牌授权照片 → 无字主视觉底图。

Preset 应说明适用输入、禁用条件和失败降级策略，而不只是保存一组默认值。

### 3. 新增场景路由

在 `photo / text / mixed` 之后继续判断交付用途：封面、Story、邀请函、展签、社媒、相册或品牌主视觉。用途路由可以自动选择画幅、安全区、文字密度和是否保留原图。

### 4. 新增确定性辅助工具

这是最值得优先扩展的方向：

- 日期与农历计算器：让节日检测不依赖 LLM 心算。
- OCR 检查器：发现编号、中文原句和禁用文字错误。
- 网格/布局检查：验证 2×2、2×3、3×3 数量和阅读顺序。
- 分割工具：为分层贴纸提供真实 Alpha，而不是完全依赖生成模型重画边缘。
- 色板提取：从原图稳定导出 3–6 色供 Prompt 使用。
- 生成清单：保存模型、输入哈希、Prompt、输出、重试原因和最终选择。

这些工具不会取代视觉判断，但会把“必须精确”的部分从概率生成移到可验证程序。

### 5. 新增质量门禁

可将当前人工清单拆成半自动信号：

- 人数与主体重复检测；
- OCR 精确匹配；
- 留白比例估算；
- 主体占画面积；
- 色彩数量和饱和度；
- 预览格数量；
- 原图与成品的身份/构图相似度。

门禁只负责暴露风险，最终美学仍需人工判断。

## 可使用场景

### 旅行与城市记忆

**输入：** 山野、街道、海边、建筑、旅伴照片。  
**输出：** 旅行记忆页、地图札记、展览票、邮票、纪念封。  
**价值：** 把普通照片转成有编辑层级的个人档案，而不是套旅行滤镜。

### 人像与日常纪念

**输入：** 自拍、家人、宠物、生活瞬间。  
**输出：** 角落胶带照片、线稿水彩、圆润粗线、小型视觉岛。  
**注意：** 不适合高精度肖像修复或证件照；需严格保持人数、姿态和身份。

### 建筑、空间与设计观察

**输入：** 建筑立面、室内、公共空间、产品结构。  
**输出：** 结构解构、档案卡、长虹玻璃、展签引用。  
**价值：** 将轴线、透视、材料和光影提炼成研究封面或田野笔记。

### 食物、花草和器物

**输入：** 咖啡、餐桌、植物、工艺品、收藏物。  
**输出：** 标本页、材料采样、档案卡和小型色彩研究。  
**价值：** 适合菜单概念、展陈提案、品牌情绪板和个人收藏记录。

### 编辑出版与内容封面

**输入：** 已授权照片、文章主题、项目概念。  
**输出：** 杂志跨页、章节页、研究报告封面、专栏题图。  
**建议：** 生成无字或短字底图，正式标题与长文案放到 Figma、InDesign 或代码排版层。

### 一句话与概念卡

**输入：** 概念、标题、短句。  
**输出：** 原句 + 一个器物、路径、开关、容器或色块关系。  
**价值：** 适合演讲章节页、研究结论卡、社媒观点卡和团队复盘材料。

### 节日与纪念节点

**输入：** 与节日相关或同期的照片。  
**输出：** 基础风格上增加一个点缀色或一个符号。  
**边界：** 不应自动虚构情侣、家庭、服装、地点或拍摄日期；商业促销不适合沿用默认的极简节日层。

### 品牌概念与活动提案

**输入：** 已授权的产品、创始人、空间、地标或活动照片。  
**输出：** 主视觉方向、邀请函底图、品牌档案页和系列情绪提案。  
**边界：** 当前 Skill 更适合概念验证，不包含 Logo 安全区、品牌色锁定、审批、批量变体或 DAM。

## 不适合的场景

- 电商商品主图、精确抠图和像素级合成。
- 证件照、肖像修复、身份敏感人脸编辑。
- 数据图表、复杂信息图和长文排版。
- 需要精确 GIS、票号、机构印章或官方文件真实性的内容。
- 大规模无人工审核的批量品牌生产。
- 需要跨模型完全一致输出的确定性流水线。

## 推荐的扩展优先级

### A. 可复现

保存输入、配置、完整 Prompt、模型版本、输出与失败版本；为每次选号建立可追踪记录。

### B. 可验证

先实现日期、OCR、网格和留白检查，再考虑增加更多风格。当前最明显风险是文字、计数和复杂组合约束。

### C. 可编辑

让原图、贴纸层、背景、文字和微图形分层输出；正式文字走确定性排版。

### D. 可生产

增加品牌预设、权限与素材来源、批量变体、审批、成本记录、版本回退和 DAM 接口。

### E. 可研究

建立跨人像、建筑、旅行、食物与文本的固定样本集，记录首次通过率、重试原因、人工选择和不同图像模型的表现。这里的重点是稳定性研究，不需要把 Skill 开关测试当作前提。
