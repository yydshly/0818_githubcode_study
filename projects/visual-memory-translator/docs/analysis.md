# Visual Memory Translator：能力、原理与真实边界

## 一句话判断

Visual Memory Translator 是一套多模态 Agent 的编辑艺术指导协议。它把“理解输入、保留什么、删掉什么、怎样组织留白、用什么媒介表达”编成可复用规则，然后把结果交给外部图像模型执行。

## 仓库组成

固定版本 `e0d04509a40e104a68ed9f3fbf5a779fe529d8c2` 包含：

- `SKILL.md`：触发条件、输入路由、主流程、决策优先级、默认参数和硬约束。
- `references/display-and-layout.md`：14 种原图呈现方式与 7 种布局。
- `references/styles.md`：18 种风格，以及新增风格需要填写的合同。
- `references/defaults-and-presets.md`：9 个智能预设与按题材自动选择规则。
- `references/systems.md`：抽象度、人物、色彩、文案、材料和输出比例。
- `references/style-preview.md`：4/6/9 格视觉试衣间协议。
- `references/text-visual.md`：一句话到单一隐喻卡的路径。
- `references/holidays.md`：中、日、美主要节日的低强度叠加规则。
- `references/quality.md`：质量检查、失败定位和重试指令。
- `outputs/`：上游公开样张。

没有 `scripts/`、依赖清单、服务端、模型权重或训练流程。

## 三条输入路径

| 输入 | 路径 | 默认行为 | 主要输出 |
| --- | --- | --- | --- |
| 照片 | `photo` | 无指定风格时先出 6 格预览 | 编辑式记忆页、档案、票据、材料转译等 |
| 一句话或概念 | `text` | 跳过风格预览 | 原句 + 一个小型视觉隐喻 |
| 照片 + 指定文案 | `mixed` | 照片作为记忆证据，文案直接进入画面 | 不额外发明金句的混合编辑页 |

## 参数化艺术指导

Skill 将一次视觉任务拆成多个相对独立的决定：

1. `original_display_mode`：原图是否出现，以及以照片、窗口、票据、贴纸等何种关系出现。
2. `layout_mode`：分栏、视觉岛、档案、不对称布局或贴纸重组。
3. `style_mode`：水彩、单线、矢量、色块、结构解构、票据、长虹玻璃、标本页等媒介语言。
4. `abstraction_level`：从低抽象到极致抽象。
5. `whitespace_level` 与 `translation_scale`：把留白和主体尺度写成强约束。
6. `text_mode`：用户原句、诗性短句、展签或无文字。
7. 人物、颜色、微图形、材料、节日和事实完整性约束。

这种拆分的价值不在于参数本身，而在于防止 Agent 直接把“艺术感”压成一个模糊形容词。

## 风格试衣间为什么重要

风格预览不是简单生成六张滤镜图。候选需要至少在媒介、版式、抽象度、原图可见性或隐喻上有显著差异，并尽量覆盖：

- 绘画 / 线条；
- 几何 / 抽象；
- 材料 / 光学；
- 编辑 / 档案。

用户选择后，预览格只作为创意方向。成品必须重新读取原始照片，以避免把低清预览放大成最终资产。这个交互是仓库最有产品价值的设计。

## 质量恢复机制

`quality.md` 把常见失败与定向修正绑定：

| 失败 | 修正方向 |
| --- | --- |
| 候选只是换滤镜 | 更换媒介、版式与抽象度，覆盖四类视觉语言 |
| 插画太大、画面太满 | 缩小到当前的 40%–60%，删除至少一半非必要元素 |
| 人像变成完整肖像 | 删除五官和皮肤纹理，恢复姿态与服装结构 |
| 三层贴纸融合成一张 | 恢复 2–3 个完整白边层和至少 50% 留白 |
| 文本卡像社交金句图 | 删除底图照片和毛玻璃，只保留纸面与一个隐喻 |
| 节日变成促销海报 | 降到一个点缀色和最多一个符号 |

它仍然是“重写 Prompt 并重试”，不是程序化检测器。是否通过通常依赖 Agent 或人工视觉判断。

## 本研究的正向能力实演

按照用户要求，本研究没有进行 Skill 开/关对照，而是直接执行它的完整工作流。

### 1. 自有原始照片

构造一张前景芦苇、中景人物与亭廊、远景水面和山体清晰分层的旅行照片，便于验证风格选择与层级重组。

### 2. 默认六格预览

一次生成得到：

- `01` 极简线稿水彩；
- `02` 极致抽象；
- `03` 分层贴纸；
- `04` 一日展览档案；
- `05` 长虹玻璃；
- `06` 结构解构。

网格、顺序、题材一致性和风格差异基本满足合同。第 04 格额外画出大号 `4`，成为可观察的文字约束失败。

### 3. 从原图生成所选成品

选择 `03` 后，重新输入原始照片，生成三层分离贴纸：人物、亭廊与步道、水面与山体。它没有把预览格放大，也没有改成完整肖像。

### 4. 文本隐喻卡

句子“不是所有答案，都需要立刻被填满。”被转成空容器与停止在入口前的线。成品保持原句、一个隐喻、一个强调色和大量空白。

## 能力边界

### Skill 能控制的

- 任务何时触发以及使用哪条输入路径。
- Agent 应当按什么顺序做视觉决策。
- Prompt 应包含哪些结构、禁止项和保留条件。
- 未指定风格时如何引入用户选择。
- 结果失败后应针对什么问题重试。

### Skill 不能保证的

- 精确分割、遮挡补全和人物身份的像素级稳定。
- 4/6/9 格数量、编号和中文排版每次都完全正确。
- “保留 15%–30% 信息”可被客观测量。
- 不同宿主和图像模型产生一致结果。
- 自动节日日期和农历换算始终正确。
- 商业资产的版权、肖像权、品牌审批与发布治理。

## 研究意义

这个仓库最适合研究四件事：

1. 怎样把隐性审美拆成可读、可版本化的规则。
2. 怎样把生成式视觉交互从“一次 Prompt”变成“预览—选择—重生成”。
3. 怎样用负面约束和失败恢复减少模型常见审美偏差。
4. 怎样为风格、预设和场景建立扩展合同，而不是无限堆提示词。
