原图记录现实，

WHEN UNCLEAR

没想好风格

先用六宫格比较艺术方向，再选择一个方向回到原图重生成。六格只承担决策，不是最终必须交付六张。

WHEN SPECIFIC

用途已经明确

直接说“做旅行明信片”或“做生日社媒封面”，Skill 会选择适合的布局、留白、画幅和文字密度。

TEXT HAS TWO JOBS

文字既能控制，也能入画

“用于七夕”可以只控制氛围；“标题只写‘岁岁欢喜’”才要求文字出现在画面里。正式长文仍建议后期排版。

NOT A GOOD FIT

这些任务不要交给它单独完成。

共同原因是任务要求确定性、精确边界或可规模化治理，而这个仓库提供的是生成式视觉指导。

  1. 证件照和精确人像修复生成模型可能改变脸、皮肤和细节。改用专用修复工具并人工复核
  2. 电商商品精确抠图生成式“贴纸层”不等于真实 Alpha 蒙版。改用分割、钢笔路径或摄影后期
  3. 百分之百保持人物身份即使写了保留约束，也不能提供身份保证。身份敏感任务需要专用管线与授权
  4. 数据图表或大量文字数字、中文和密集排版可能出现错误。图表用代码，长文用 Figma / InDesign
  5. 无人审核的大规模品牌生产缺少版权、审批、一致性和资产治理。必须增加质检、审批和 DAM 流程
06 / HONEST LIMITS

它值得研究，
但不是确定性软件。

  • 没有模型或算法仓库不训练模型，也不直接渲染像素。
