原图记录现实，

WHEN UNCLEAR

没想好风格

先用六宫格比较艺术方向，再选择一个方向回到原图重生成。六格只承担决策，不是最终必须交付六张。

WHEN SPECIFIC

用途已经明确

直接说“做旅行明信片”或“做生日社媒封面”，Skill 会选择适合的布局、留白、画幅和文字密度。

TEXT HAS TWO JOBS

文字既能控制，也能入画

“用于七夕”可以只控制氛围；“标题只写‘岁岁欢喜’”才要求文字出现在画面里。正式长文仍建议后期排版。

STEP 01 / SOURCE

先建立事实证据

一人、红褐色长外套、亭廊、水面、远山与前景芦苇。前中远景清晰，适合验证分层与结构转译。

STEP 02 / STYLE FITTING ROOM

一次生成六种艺术指导

  1. 01线稿水彩
  2. 02极致抽象
  3. 03分层贴纸
  4. 04展览档案
  5. 05长虹玻璃
  6. 06结构解构

真实偏差：04 格额外生成了一个大号“4”。网格与风格成立，但精确文字合同仍不是确定性能力。

选择 03，必须回到原图。

成品不裁切、不放大宫格单元，而是重新读取原始照片，把人物、亭廊与步道、水面与山体组成三张完整白边层。拖动滑杆查看输入与结果。

text 路径默认跳过六格预览。这里保留原句，只使用“空容器 + 停在入口前的线”，没有底图照片、完整故事、图标矩阵或鸡汤标题。

NOT A GOOD FIT

这些任务不要交给它单独完成。

共同原因是任务要求确定性、精确边界或可规模化治理，而这个仓库提供的是生成式视觉指导。

  1. 证件照和精确人像修复生成模型可能改变脸、皮肤和细节。改用专用修复工具并人工复核
  2. 电商商品精确抠图生成式“贴纸层”不等于真实 Alpha 蒙版。改用分割、钢笔路径或摄影后期
  3. 百分之百保持人物身份即使写了保留约束，也不能提供身份保证。身份敏感任务需要专用管线与授权
  4. 数据图表或大量文字数字、中文和密集排版可能出现错误。图表用代码，长文用 Figma / InDesign
  5. 无人审核的大规模品牌生产缺少版权、审批、一致性和资产治理。必须增加质检、审批和 DAM 流程
06 / HONEST LIMITS

它值得研究，
但不是确定性软件。

  • 没有模型或算法仓库不训练模型，也不直接渲染像素。
  • 精确文字仍会失败本次预览已出现额外数字。
  • 分割依赖生成模型三层贴纸不是可导出的真实 Alpha 管线。
  • 跨模型结果不一致同一 Skill 在不同宿主上的遵循度会变化。
  • 不含生产治理版权、肖像、品牌审批、批量变体和 DAM 需要另建系统。
