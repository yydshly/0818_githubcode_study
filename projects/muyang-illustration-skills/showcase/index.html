五层流程，只有最后一层真正画图

        
上游的工程价值主要在“限制 Agent 怎么做”，而不是增加底层模型能力。

05 / FROM IMAGE TO PRODUCT
两条扩展，解决“可控”与“可交付”

        
当前 Skill 只生产风格化底图。要把它升级为真实产品，需要分别解决人物画面一致性与文字内容准确性；两者不是继续堆 Prompt 就能完成。

      


      

        

          
TRACK A / CONSISTENCY参考图驱动的图生图后期实现

          
文字只能弱控制“画什么”；参考图和保留合同才能约束“必须还是这个人、这套衣服和这个画面”。

          

            
01参考图片人物、产品或原始画面

            →
            
02保留合同身份、脸、服装、姿态、构图

            →
            
03图像编辑显式传图，不是只写 Prompt

            →
            
04一致性质检不合格则重试或人工确认

          

          

            
必须保留
人物身份、脸部特征、发型、服装、姿态、镜头与产品结构。

            
允许改变
插画材质、色板、光影、背景简化程度和风格强度。

          

          
关键边界：只修改 Skill 文案不够；Skill 还必须把参考图片真正传给支持图像编辑的工具。

        


        

          
TRACK B / TYPOGRAPHY确定性文字产品化后期实现

          
有文字才可能成为封面、海报或社媒卡，但文字不能依赖模型随机画出来，必须由系统准确排版。

          

            
01无字底图Skill 生成干净插画资产

            →
            
02内容字段标题、副标题、品牌、日期

            →
            
03模板排版HTML / SVG / Canvas

            →
            
04成品质检准确性、安全区、对比度、溢出

          

          

            小说封面 / 1600 × 2560
            盛夏以前
            
关于告别与重逢 · 林川

          

          
关键边界：模型自动生成的杂志文字即使好看，也可能错误或不可编辑；产品文字必须由确定性排版层负责。

        

      


      

        目标产品结构
        参考图与内容字段 → Skill 路由与保留合同 → ImageGen 底图/编辑 → 确定性排版 → 一致性与文字质检 → 可交付资产
      

    


    

      

        
06 / LIMITS
现在能证明什么，不能证明什么

      

      

        
观察当前结论证据强度

        
仓库存在 9 个 Skill 和 25 套配方结构完整，可安装和调用强

        
每种风格有一张上游示意图能说明作者定义的视觉方向中

        
统一主体覆盖 8 个分类各 1 张能证明基础路由与明显风格差异强

        
每个代表风格目前只有一次入选结果仍不能证明重复生成稳定性与成功率不足

        
资产只在文档中用于核对当前是文生图，不是参考图重绘强

        
部分配方隐含人物与时装假设动物、建筑、产品可能出现语义冲突中

07 / LATER, NOT NOW
后期扩展先做评测，再增加能力

        
以下均为研究路线，当前没有实现。重点不是继续堆 Prompt，而是先获得可复现证据。

      

      

        
01可复现基线
统一主体与重复采样
固定模型、版本、尺寸和元数据；人物、动物、场景各生成多次，保留成功与失败。

        
02质量门禁
兼容矩阵与配方回归
记录风格 × 主体 × 模型的适配，做 Prompt 消融和版本化回归。

        
03图生图
参考图 + 保留合同
明确身份、姿态、构图和产品结构哪些必须保留，哪些允许风格化。

        
04产品化
版本、成本与权利追踪
增加调用记录、团队审批、资产来源、批量任务和失败审核。
